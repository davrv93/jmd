Cómo se juega

  1. Una barra sube y baja. Tócala cuando pase por la franja amarilla.
  2. Más cerca del centro, más chance de encestar. Ni el tiro perfecto es seguro.
  3. Puedes tirar cada 2,5 segundos. Cada enceste acelera la barra.
  4. Al llegar a 3 encestes, el sistema sortea tu premio entre los cupos que quedan.
