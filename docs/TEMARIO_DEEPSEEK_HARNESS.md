## Resultado final

Un repositorio con instrucciones de trabajo para el agente, un informe comparativo del consumo y un paquete de documentación validada: README, mapa de componentes, flujos principales y guía de ejecución y diagnóstico.

## Sesión 1 · Entiende tu sistema con DeepSeek Harness

- Diferenciar modelo, harness, herramientas y contexto.
- Configurar DeepSeek Harness, el proveedor y el espacio de trabajo.
- Recorrer un repositorio por etapas: puntos de entrada, componentes, dependencias y flujos.
- Pedir un plan y distinguir lo observado en archivos de lo que falta verificar.
- Preparar instrucciones del proyecto para que el agente no relea todo en cada tarea.

**Entregable:** mapa inicial del sistema con referencias a archivos y un listado de dudas verificables.

## Sesión 2 · Mide y reduce el consumo

- Registrar una tarea de referencia: tiempo, llamadas, contexto y tokens cuando el proveedor los informe.
- Separar el consumo de la API del uso de CPU y RAM de las herramientas locales.
- Acotar búsquedas, archivos y salidas de terminal; reutilizar resúmenes revisados y dividir tareas por responsabilidad.
- Evitar llamadas repetidas y verificar cada cambio con las comprobaciones pertinentes.
- Comparar la misma tarea antes y después, conservando criterios de calidad equivalentes.

**Entregable:** informe de consumo antes/después y una rutina de trabajo reproducible. El ahorro se mide; no se promete un porcentaje fijo.

## Sesión 3 · Documenta sin inventar y deja el sistema mantenible

- Redactar README, arquitectura, flujos de datos y decisiones técnicas desde evidencias del repositorio.
- Crear diagramas Mermaid y guías de instalación, configuración y diagnóstico.
- Comprobar rutas, comandos y ejemplos; marcar supuestos y documentación pendiente.
- Establecer una revisión de documentación cuando cambien los módulos del sistema.

**Entregable:** paquete de documentación validada y un procedimiento breve para actualizarlo.
