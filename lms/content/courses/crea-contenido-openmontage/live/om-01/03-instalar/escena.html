Instala OpenMontage

Necesitas Python, Node.js y FFmpeg. Copia el comando, pégalo en la terminal dentro de la carpeta del proyecto y espera.

  1. 1
    Verifica FFmpegSi no lo tienes, instálalo desde ffmpeg.org o con Homebrew.
  2. 2
    Descarga el proyectoDesde el repositorio oficial de OpenMontage.

Comando de instalación

make setup

Si no tienes «make»

python3 -m venv .venv && source .venv/bin/activate && python -m pip install -r requirements.txt && cd remotion-composer && npm install && cd .. && python -m pip install piper-tts

En Windows, el comando es distinto: pídele al asistente que lo adapte a PowerShell.
