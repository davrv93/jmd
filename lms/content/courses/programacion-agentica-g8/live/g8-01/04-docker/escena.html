Experiencia Grupo 8 · E04

Instala Docker según tu sistema

Docker es una caja que lleva el programa con todo lo que necesita.

Windows Primero WSL

  • En PowerShell como administrador: wsl --install
  • Reinicia e instala Docker Desktop
  • Activa «Use WSL 2 based engine»

macOS Docker Desktop

  • Instala Docker Desktop
  • Elige tu chip: Apple o Intel
  • Ábrelo y espera a que arranque

Linux Docker Engine

  • Instala Docker Engine con la guía oficial
  • sudo usermod -aG docker $USER
  • Cierra sesión y vuelve a entrar
