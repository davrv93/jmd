Le das el caso de prueba (E02) 
ID: E2E-VEN-002 efectivo-insuficiente
Semilla: cajero · Agua San Luis
        625 ml S/ 1,80 · stock 60
Pasos: entrar → agregar el agua
       → efectivo 0,90 → Cobrar
Esperado: «Efectivo insuficiente»,
          no se crea la venta,
          stock sigue en 60
La IA propone el spec, con tus page objects 
test('E2E-VEN-002 efectivo-insuficiente',
  async ({ page }) => {
  const venta = new VentaPage(page);
  await venta.abrir();
  await venta.agregar('Agua San Luis 625 ml');
  await venta.cobrar({ efectivo: '0.90' });
  await expect(venta.aviso).toHaveText(
    'Efectivo insuficiente');
  await expect(venta.stock('Agua')).toHaveText('60');
});

Tú revisas: ¿verifica TODO el resultado esperado (el aviso y el stock)? Una prueba que solo mira el aviso deja pasar la venta fantasma.
