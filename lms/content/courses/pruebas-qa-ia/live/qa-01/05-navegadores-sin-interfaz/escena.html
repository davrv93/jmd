Memoria

Según el proyecto: Obscura publica ≈ 85 ms y ≈ 30 MB frente a ≈ 500 ms y 200+ MB de Chrome; Lightpanda publica ≈ 11× más rápido y ≈ 9× menos memoria en su benchmark de rastreo. Son benchmarks distintos: no se comparan entre sí. Para eso medimos.

✓ sí · ✗ no · ⚠ cuidado · «en clase»: lo probamos hoy y anotamos. Lightpanda no dibuja la página: sin render no hay capturas ni pruebas visuales.

// Chromium: Playwright lo lanza y lo cierra solo
const browser = await chromium.launch();  // headless por defecto

// Lightpanda u Obscura: arrancas su servidor CDP y te conectas
// $ lightpanda serve --host 127.0.0.1 --port 9222
const remoto = await chromium.connectOverCDP('ws://127.0.0.1:9222');
const ctx = await remoto.newContext();
const page = await ctx.newPage();
await page.goto('/venta');  // el mismo page object de siempre

⚠ El puerto CDP no pide clave. Quien llegue al 9222 controla el navegador: navega como tú y lee tus cookies. Escúchalo solo en 127.0.0.1; nunca en 0.0.0.0 ni publicado con -p 9222:9222 en Docker. Obscura además trae un modo «sigilo» para no parecer un bot: úsalo solo donde tengas permiso.

Tus page objects no cambian: cambia solo cómo obtienes el browser.
