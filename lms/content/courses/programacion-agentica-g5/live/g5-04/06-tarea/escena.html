Pregunta para el hilo de la sesión

En tu bot, ¿qué debería decidir el código y qué el modelo? Da un ejemplo de cada uno.

Tarea extra · se entrega desde el LMS

  1. Instala Ollama y baja el modelo pequeño: ollama pull qwen3:0.6b
  2. Mide: ollama run qwen3:0.6b --verbose "…" 2> medicion.txt y anota eval rate y la RAM de ollama ps
  3. Sube medicion.txt y EVIDENCIA.md (tokens/s, RAM, tu procesador y el caso en que el motor se equivocó) a tu repo clase-extra y entrega URL + commit

Modelo local

Pesos × bytes + caché KV + motor. Q8 de 0.6B: 1,3 GB y 14 tok/s en 2 vCPU.

Motor

Hechos con nombre → fila → acción. El modelo propone; el código decide.

Embeddings

Frases con el mismo sentido caen cerca. e5 + regresión: de 66 % a 78 %.
