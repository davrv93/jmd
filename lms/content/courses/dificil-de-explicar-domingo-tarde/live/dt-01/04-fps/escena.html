Regla de oro: mueve por tiempo, no por cuadro

Si sumas «3 píxeles por cuadro», en una compu lenta todo va más lento. Si calculas la posición con el tiempo (segundos), se ve igual de rápido a 12 o a 60 fps: solo cambia lo suave.

// p5.js
frameRate(24);                 // cuadros por segundo
const t = millis() / 1000;     // tiempo en segundos
x = 100 + 80 * t;              // por tiempo ✓

// Three.js
const t = performance.now() / 1000;

// GSAP / HyperFrames: todo se mide en segundos
gsap.to(gato, { x: 300, duration: 2 });
