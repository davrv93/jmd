¿Por qué una sola? FLUX no recuerda: cada vez que generas, cambian un poco la cara, el encuadre y los colores. Para animar no generas 24 imágenes por segundo: eliges una base y el movimiento lo pone el código (p5, Three.js, GSAP). Las variaciones sirven para elegir, no para animar.
