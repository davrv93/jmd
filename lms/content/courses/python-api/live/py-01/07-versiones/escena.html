Varias versiones, en paz

  1. Instala también Python 3.11 
    PS> winget install -e --id Python.Python.3.11
  2. Mira las versiones que tienes · el lanzador py las conoce todas 
    PS> py -0p
  3. Elige una al correr 
    PS> py -3.11 --version
  4. Y la otra 
    PS> py -3.13 --version
  1. Instala pyenv 
    $ brew install pyenv
  2. Conéctalo a tu terminal (zsh) y abre una terminal nueva 
    echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.zshrc
echo '[[ -d $PYENV_ROOT/bin ]] && export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(pyenv init - zsh)"' >> ~/.zshrc
  3. Instala 3.11 y fíjala en esta carpeta · tarda unos minutos 
    $ pyenv install 3.11.10 && pyenv local 3.11.10
  4. Comprueba 
    $ python --version
  1. Herramientas para compilar Python · Ubuntu o Debian 
    $ sudo apt update && sudo apt install -y build-essential libssl-dev zlib1g-dev libbz2-dev libreadline-dev libsqlite3-dev libncursesw5-dev xz-utils tk-dev libxml2-dev libxmlsec1-dev libffi-dev liblzma-dev
  2. Instala pyenv 
    $ curl -fsSL https://pyenv.run | bash
  3. Conéctalo a tu terminal (bash) y abre una terminal nueva 
    echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.bashrc
echo '[[ -d $PYENV_ROOT/bin ]] && export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(pyenv init - bash)"' >> ~/.bashrc
  4. Instala 3.11 y fíjala en esta carpeta 
    $ pyenv install 3.11.10 && pyenv local 3.11.10 && python --version

Conviven, no se pisan. El lanzador py elige cuál corre.pyenv local deja un .python-version: esa carpeta usa esa versión.
