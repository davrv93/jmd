Instala Python 3

  1. Instala Python 3.13 · o descárgalo de python.org y marca «Add python.exe to PATH» 
    PS> winget install -e --id Python.Python.3.13
  2. Cierra la terminal y abre una nueva
  3. Comprueba la versión 
    PS> py --version
  1. ¿Sin Homebrew? Instálalo · si ya lo tienes, salta al paso 2 
    $ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Instala Python 3.13 · o usa el instalador de python.org 
    $ brew install python@3.13
  3. Comprueba la versión 
    $ python3 --version
  1. Instala Python, venv y pip · Ubuntu o Debian 
    $ sudo apt update && sudo apt install -y python3 python3-venv python3-pip
  2. Comprueba la versión 
    $ python3 --version
