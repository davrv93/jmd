Imagen y contenedor

DockerfileLa receta: de qué Python partes y qué copias.
ImagenLa receta ya preparada y congelada. Ej.: python:3.13-slim
ContenedoresCada docker run sirve uno nuevo. --rm lo borra al terminar.

Un Dockerfile de 4 líneas

FROM python:3.13-slimparte de una imagen con Python 3.13
WORKDIR /apptrabaja dentro de /app
COPY hola.py .mete tu script
CMD ["python", "hola.py"]lo que corre al arrancar

Corres la misma imagen 3 veces. ¿Cuántos contenedores nacen?

Cambiar de Python es cambiar una palabra: python:3.11 o python:3.13
