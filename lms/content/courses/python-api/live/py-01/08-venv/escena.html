Un venv por proyecto

  1. Una carpeta para tu proyecto
    PS> mkdir mi-proyecto; cd mi-proyecto
  2. Crea el venv
    PS> py -3.13 -m venv .venv
  3. Actívalo · si PowerShell lo bloquea: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
    PS> .venv\Scripts\Activate.ps1
  4. Instala una librería
    (.venv) PS> pip install requests
  5. Anota lo que usa el proyecto
    (.venv) PS> pip freeze > requirements.txt
  1. Una carpeta para tu proyecto
    $ mkdir mi-proyecto && cd mi-proyecto
  2. Crea el venv
    $ python3 -m venv .venv
  3. Actívalo
    $ source .venv/bin/activate
  4. Instala una librería
    (.venv) $ pip install requests
  5. Anota lo que usa el proyecto
    (.venv) $ pip freeze > requirements.txt
