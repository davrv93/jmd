Tu script en 3.11 y 3.13

  1. En la carpeta de hola.py, córrelo en Python 3.11 · la primera vez descarga la imagen 
    PS> docker run --rm -v "${PWD}:/app" -w /app python:3.11 python hola.py
    $ docker run --rm -v "$PWD":/app -w /app python:3.11 python hola.py
  2. Ahora en Python 3.13: cambia solo el número 
    PS> docker run --rm -v "${PWD}:/app" -w /app python:3.13 python hola.py
    $ docker run --rm -v "$PWD":/app -w /app python:3.13 python hola.py
  3. Empaquétalo: guarda este Dockerfile junto a hola.py
    Archivo Dockerfile (sin extensión)
    FROM python:3.13-slim
WORKDIR /app
COPY hola.py .
CMD ["python", "hola.py"]
  4. Constrúyelo y córrelo 
    $ docker build -t hola . && docker run --rm hola
