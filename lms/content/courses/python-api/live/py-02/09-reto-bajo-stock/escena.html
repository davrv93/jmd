# Pégalo en main.py ANTES de @app.get("/productos/{producto_id}")

@app.get("/productos/bajo-stock")
def bajo_stock(limite: int = 5):
    return [p for p in productos.values() if p["stock"] < limite]


@app.get("/categorias")
def categorias():
    return sorted({p["categoria"] for p in productos.values()})
  1. limite: int = 5 en la función se vuelve ?limite=5 en la URL. Swagger lo muestra como un campo.
  2. productos.values() te da cada producto, que es un dict. El filtro es el mismo del ejercicio 6 del laboratorio.
  3. Para las categorías: un set comprehension quita los repetidos y sorted() lo devuelve como lista ordenada (JSON no tiene set).

El orden de las rutas importa

FastAPI revisa las rutas de arriba hacia abajo y usa la primera que encaja.

1 · /productos/bajo-stock ← primero la fija
2 · /productos/{producto_id} ← después la variable

Al revés, bajo-stock se toma como un producto_id, no es un número y la respuesta es 422: «Input should be a valid integer».
