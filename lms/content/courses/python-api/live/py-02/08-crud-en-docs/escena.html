Tu CRUD en /docs

En Swagger: abre una ruta, pulsa Try it out, pega el body y pulsa Execute. Mira el código de respuesta.

  1. POST/productos · crea dos productos → 201 
    {"nombre": "Arroz", "precio": 4.5, "stock": 40, "categoria": "abarrotes"}
    {"nombre": "Detergente", "precio": 6.5, "stock": 2, "categoria": "limpieza"}
  2. GET/productos · lista → 200 · ves los dos, con id 1 y 2
  3. PUT/productos/{producto_id} · en producto_id pon 1 y sube el precio → 200 
    {"nombre": "Arroz", "precio": 5.2, "stock": 38, "categoria": "abarrotes"}
  4. DELETE/productos/{producto_id} · borra el 2 → 204 · pídelo con GET: ahora da 404
  5. POST/productos · manda un body malo → 422 
    {"nombre": "Aceite", "precio": -3, "stock": "muchos", "categoria": "abarrotes"}
// 422 · así responde FastAPI (recortado)
{"detail": [
  { "loc": ["body", "precio"],
    "msg": "Input should be greater than 0" },
  { "loc": ["body", "stock"],
    "msg": "Input should be a valid integer…" }
]}

loc dice dónde está el error (en el body, campo precio). msg dice qué regla falló. Tu función ni se ejecutó: Pydantic lo frenó antes.
