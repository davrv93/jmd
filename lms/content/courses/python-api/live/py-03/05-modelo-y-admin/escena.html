Tu modelo y el admin

Los comandos son iguales en Windows, macOS y Linux · siempre con (.venv) activo, dentro de mi-django

  1. Pega models.py (derecha) en inventario/models.py y guarda
  2. Crea la migración · Django compara tu clase con la base y escribe el plan 
    (.venv) > python manage.py makemigrations
    Migrations for 'inventario':
  inventario/migrations/0001_initial.py
    + Create model Producto
  3. Aplícala · crea db.sqlite3 con todas las tablas 
    (.venv) > python manage.py migrate
      Applying inventario.0001_initial... OK
  4. Crea tu usuario administrador · la contraseña no se ve al escribir; el correo puede ir vacío 
    (.venv) > python manage.py createsuperuser
    Nombre de usuario (leave blank to use '…'): admin
Dirección de correo electrónico:
Password:
Password (again):
Superuser created successfully.
  5. Pega admin.py (derecha) en inventario/admin.py y levanta el servidor
    (.venv) > python manage.py runserver
  6. Entra a /admin/ → Productos → Añadir producto y crea estos 3
    nombrepreciostockcategoria
    Arroz4.5040abarrotes
    Detergente6.502limpieza
    Leche4.2012lácteos
  7. Busca «arroz», filtra por categoría y prueba un precio de -3 · sale en rojo: «Asegúrese de que este valor es mayor o igual a 0.01.»
from decimal import Decimal

from django.core.validators import MinValueValidator
from django.db import models


class Producto(models.Model):
    nombre = models.CharField(max_length=100)
    precio = models.DecimalField(
        max_digits=10, decimal_places=2,
        validators=[MinValueValidator(Decimal("0.01"))],  # mayor que 0
    )
    stock = models.PositiveIntegerField(default=0)  # 0 o más
    categoria = models.CharField(max_length=50)

    def __str__(self):
        return f"{self.nombre} (stock {self.stock})"

from django.contrib import admin

from .models import Producto


@admin.register(Producto)
class ProductoAdmin(admin.ModelAdmin):
    list_display = ["id", "nombre", "precio", "stock", "categoria"]
    search_fields = ["nombre", "categoria"]
    list_filter = ["categoria"]
