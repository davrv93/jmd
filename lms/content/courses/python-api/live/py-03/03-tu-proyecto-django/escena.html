Tu proyecto Django

  1. Abre la terminal donde está mi-api (clase 2) y crea mi-django al lado
    PS> mkdir mi-django; cd mi-django
  2. Un venv nuevo, solo para Django · si PowerShell lo bloquea: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
    PS> py -m venv .venv
    PS> .venv\Scripts\Activate.ps1
  3. Instala Django y mira su versión
    (.venv) PS> pip install django
    (.venv) PS> django-admin --version
  4. Crea el proyecto · con el punto al final: deja manage.py aquí mismo
    (.venv) PS> django-admin startproject config .
  5. Crea la app del inventario
    (.venv) PS> python manage.py startapp inventario
  6. Abre la carpeta y edita config/settings.py como a la derecha
    (.venv) PS> code .
  7. Levántalo y abre el navegador
    (.venv) PS> python manage.py runserver
