Tu API con DRF y Swagger

Iguales en Windows, macOS y Linux · con (.venv) activo, dentro de mi-django

  1. Detén el servidor (Ctrl+C) e instala DRF y drf-spectacular
    (.venv) > pip install djangorestframework drf-spectacular
  2. En config/settings.py, debajo de 'inventario', agrega · con guion bajo, no guion
        'rest_framework',
    'drf_spectacular',
  3. Pega los 4 archivos de la derecha · settings.py va al final; serializers.py es nuevo; views.py y urls.py se reemplazan enteros
  4. Levántalo y abre Swagger en /api/docs/
    (.venv) > python manage.py runserver
  5. En Swagger, con Try it out → Execute, recorre el CRUD:
    POST/api/productos/ → 201 · sale con id 4 (los 3 del admin ya existen) 
    {"nombre": "Aceite", "precio": 9.9, "stock": 15, "categoria": "abarrotes"}
    GET/api/productos/ → 200 · GET/api/productos/{id}/ con 4 → 200 PUT/api/productos/{id}/ con 1 → 200 
    {"nombre": "Arroz", "precio": 5.2, "stock": 38, "categoria": "abarrotes"}
    DELETE/api/productos/{id}/ con 2 → 204 · pídelo otra vez: 404 POST con un body malo → 400

from rest_framework import viewsets

from .models import Producto
from .serializers import ProductoSerializer

    """Listar, ver, crear, editar y borrar productos."""

    serializer_class = ProductoSerializer

¿Por qué 400 y no 422? FastAPI usa 422 (Unprocessable Content: el JSON llegó bien armado, pero no cumple las reglas). DRF usa 400 (Bad Request) para todo dato inválido. Los dos son 4xx: el error está en lo que mandaste. Cambia la forma: FastAPI da una lista detail con loc y msg; DRF, cada campo con sus mensajes.
