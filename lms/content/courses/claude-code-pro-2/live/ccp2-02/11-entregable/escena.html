Seis consejos para llevarte

  1. Di la decisión

    No solo «hazme un dashboard»: di qué quieres saber y para qué.

  2. Pide el plan antes de construir

    Cifras, gráficos y filtros. Corregir el plan es gratis.

  3. Un cambio a la vez

    Un pedido por mensaje, así nada se pierde.

  4. Un chat nuevo por tablero

    La mesa de Claude se llena: un chat largo recuerda peor.

  5. El manual de tableros, subido una vez

    La skill build-dashboard queda en tu cuenta y Claude la usa cuando hace falta.

  6. Comprueba las cifras

    Suma una sede en Excel antes de mostrar el tablero.
