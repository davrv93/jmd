Qué significa «aislada»

Tu código es tu tienda. Sus ventas, su semilla y sus bugs son solo tuyos. Reiniciar mi tienda y /api/caos actúan solo en la tuya: nadie puede tumbar la de otro.

Se borra tras 30 min sin actividad. Si recibes 410, abre /tienda-sol/ otra vez y copia el código nuevo.

Viene con bugs a propósito (interruptor en el login). La app local (app/) queda como plan B sin internet.

Guarda tu URL en una variable (desde pruebas/)

            
Con BASE_URL, Playwright no levanta nada local: todas las pruebas apuntan a tu tienda de la nube.

          

        

      

    


    

      

        

          

            
Dos comandos · solo la carpeta pruebas/ (≈ 150 MB con Chromium)

            
# descomprime qa-taller-kit.zip y abre una terminal ahí
cd pruebas
npm install
npx playwright install chromium   # Linux: --with-deps
node -v                           # v20, v22 o v24

            
Node 20 LTS o más nuevo (nodejs.org) y Chrome. Docker Desktop es opcional (Lightpanda, Obscura, Grafana).
