Instala RTK y activa el hook

Doce minutos. Al final tu agente usa RTK solo, sin que cambies cómo trabajas.

1 Instala

$ brew install rtk
$ curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh
PS> winget install rtk-ai.rtk

2 Comprueba

$ rtk --version

3 Activa el hook de tu agente

$ rtk init -g # Claude Code
$ rtk init -g --opencode # además, OpenCode

4 ¿Reescribe?

$ rtk rewrite "git status"

Debe responder rtk git status. Cierra y abre tu agente para que tome el hook.

Si falla: «command not found» en Linux → abre otra terminal o agrega ~/.local/bin al PATH. Sin winget → usa WSL y la pestaña de Linux. ¿Sigue? Pega el error completo en el muro de esta escena.
