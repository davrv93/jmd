Plugin = código + capa de configuración

Empaqueta una capacidad como bundle

Un .zip sirve para transportarlo. DSH instala la carpeta extraída —o un paquete npm/tarball— en un perfil.

01 · CÓDIGOindex.js exporta apply(ctx).
02 · CAPAcordis.patch.yml inserta el plugin.
03 · MANIFIESTOpackage.json declara dsh.bundle.
04 · PERFILInstala y verifica la configuración compuesta.

Estructura mínima

mi-plugin/
├── package.json
├── cordis.patch.yml
└── index.js

Manifiesto clave: "dsh":{"bundle":{"patch":"./cordis.patch.yml"}}

Empaquetado e instalación

zip -r mi-plugin.zip mi-plugin transporta el proyecto.

Extrae el zip y ejecuta dsh plugin --profile <perfil> add ./mi-plugin.

En perfiles CLI comprueba con dsh --profile <perfil> --dump-config. En Desktop, reinicia la app y verifica que aparezca la herramienta o skill: ese perfil lo administra Electron y puede rechazar --dump-config.

No confundas zip con formato instalable

La guía oficial distribuye bundles como carpeta, npm, GitHub o pnpm pack (.tgz). En el aula puedes adjuntar el zip y pedir a DSH que lo extraiga e instale; verifica siempre el perfil y el nombre del bundle.

Pedido copiable

Haz que DSH construya y compruebe el bundle

Crea en una carpeta mi-plugin un bundle mínimo para DeepSeek Harness: package.json con name dsh-mi-plugin, type module, main index.js, files y dsh.bundle.patch; cordis.patch.yml que inserte el módulo; e index.js con export name y apply(ctx). Valida JSON y YAML, crea mi-plugin.zip para transportarlo y explícame cómo instalar la carpeta extraída en el perfil que estoy usando. Antes de instalar, lista el contenido y advierte si ejecutará scripts. Después verifica el bundle con --dump-config. No inventes el nombre del perfil: pregúntame o detecta el perfil actual.
