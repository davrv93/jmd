Práctica: carga los datos

Las ventas de 4 boticas de enero a octubre de 2026, con errores a propósito. Primero las cargamos tal cual, como texto.

Paso 1 · Tabla cruda (todo como texto)
CREATE TABLE ventas_crudo (
  fecha String, sede String, categoria String,
  unidades String, venta String, margen String
) ENGINE = MergeTree ORDER BY tuple();
Paso 2 · Cargar el CSV de ejemplo
INSERT INTO ventas_crudo
SELECT * FROM url('https://raw.githubusercontent.com/davrv93/jmd/main/lms/content/courses/bi-clickhouse/materials/ventas-sucio.csv', 'CSVWithNames',
  'fecha String, sede String, categoria String, unidades String, venta String, margen String');
Paso 3 · Cuenta las filas
SELECT count() FROM ventas_crudo;

Debe salir 6 144. Anótalo: es tu cifra de partida.

¿Cuántas filas te salió?
¿Por qué todo como texto? Porque si una fecha viene mal escrita, la carga no falla: la arreglamos después, a la vista.
