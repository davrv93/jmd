Experimentación Dashboards y BI · S1 · 08/13

Levanta tu propio ClickHouse

Los mismos comandos del video de la sesión, en Windows, Mac o Linux. Copia, pega y comprueba.

1

Instala Docker · Windows 10 u 11

Abre PowerShell como administrador y activa WSL 2. Luego reinicia la PC.

wsl --install

Instala Docker Desktop desde docker.com/products/docker-desktop y ábrelo hasta que diga «Engine running».

2

Levanta ClickHouse

En PowerShell cada línea termina con el acento grave (`), no con la barra.

docker run -d --name ch-taller `
  -p 8123:8123 -p 9000:9000 `
  -e CLICKHOUSE_USER=taller -e CLICKHOUSE_PASSWORD=taller123 `
  -e CLICKHOUSE_DEFAULT_ACCESS_MANAGEMENT=1 `
  -v ch_datos:/var/lib/clickhouse `
  --ulimit nofile=262144:262144 `
  clickhouse/clickhouse-server
3

Comprueba que responde

Debe contestar Ok. También puedes abrir http://localhost:8123/play en Chrome (usuario taller, clave taller123).

curl.exe http://localhost:8123/ping
4

Entra al cliente

Ya puedes escribir SQL. Sigue con la práctica de carga en esta misma ventana.

docker exec -it ch-taller clickhouse-client --user taller --password taller123

1

Instala Docker · Linux (Ubuntu, Debian, Fedora)

Instala Docker con el script oficial y agrega tu usuario al grupo docker. Cierra sesión y vuelve a entrar.

curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

¿Cómo vas?
Si algo falla
  • Puerto ocupado: otro programa usa el 8123. Cambia -p 8123:8123 por -p 18123:8123 y usa ese puerto.
  • «name is already in use»: ya lo creaste. Enciéndelo con docker start ch-taller.
  • «Cannot connect to the Docker daemon»: abre Docker Desktop y espera a que diga «Engine running».

Tus datos viven en el volumen ch_datos: si apagas la PC, siguen ahí. Para encenderlo otro día: docker start ch-taller.
