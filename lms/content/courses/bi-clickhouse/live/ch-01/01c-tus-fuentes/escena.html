Teoría 3 de 3 · Fuentes de datos

Tus archivos y bases llegan por la misma puerta

  1. Tus datos viven en varios sitios

    Un Excel en tu laptop, una base de Access heredada, un CSV en OneDrive, la base del sistema de ventas. Cada uno con su formato.

  2. Una sola puerta: las funciones de tabla

    ClickHouse lee cada fuente con una función: file() para un archivo, url() para un enlace, s3() para la nube, postgresql() y mysql() para bases. Siempre con el mismo SELECT.

  3. Excel y Access pasan por CSV

    ClickHouse no abre un .xlsx ni un .accdb directo. Guárdalos antes como CSV UTF‑8, para que las tildes y la ñ lleguen bien, y entran por file().

  4. Caso: entra todo, también lo sucio

    Con las ventas de ejemplo entraron 6 144 filas. Pero la venta por sede salió partida: «Lima Centro», «lima centro» y «LIMA CENTRO» cuentan como tres sedes distintas.

    Consulta real del video de la sesión: CREATE TABLE ventas ENGINE = MergeTree ORDER BY tuple() AS SELECT * FROM file('ventas-sucio.csv', CSVWithNames).

  5. Tu archivo, por la misma puerta

    Tu archivo entra igual. Cargar es rápido; lo que toma trabajo es limpiar sin perder filas ni totales. Para eso usamos a Claude o DeepSeek, y comprobamos cada paso.
