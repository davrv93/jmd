Un archivo es una foto; el servidor se actualiza solo

  1. El archivo es una foto

    El dashboard que descargas es un archivo que abre sin internet y se envía por correo o WhatsApp. Pero es una foto: muestra los datos del día en que lo bajaste.

  2. En el servidor, una tabla

    El SQL que genera tu dashboard crea la tabla ventas_dashboard en tu ClickHouse con tus filas limpias. Ahí viven los datos, no en el archivo.

  3. Una vista que se refresca sola

    Una vista materializada refrescable vuelve a calcular el resumen cada hora: REFRESH EVERY 1 HOUR. Nadie corre la macro; el servidor lo hace.

    Para forzarlo ahora: SYSTEM REFRESH VIEW ventas_mes_mv.

  4. Probado con tus datos de ejemplo

    Con las ventas de ejemplo, la vista resumió 6 080 filas en 40, diez meses por cuatro sedes, y la venta total cuadró al céntimo: S/ 5 562 110,68.

    Prueba hecha en ClickHouse 26.10 con el mismo SQL que descargarás.

  5. Publicar

    Un tablero como Grafana, Metabase o CH-UI se conecta a ClickHouse y siempre muestra lo último. Hoy compartes el archivo; cuando tengas servidor, compartes el tablero.
