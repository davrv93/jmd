🕸️ Graphify

1 · Instala (Python)
$ uv tool install graphifyy
o, sin uv
$ pipx install graphifyy
2 · El skill /graphify en tu agente
$ graphify install
3 · El grafo del código (sin LLM)
$ graphify update .

Si falla: sin uv ni pipx, python3 -m pip install graphifyy. «graphify: not found» → abre otra terminal.

🧠 Cortex

1 · Crea la memoria (Node 22.16 o más)
$ npx cortexboard init
2 · Abre el tablero
$ npx cortexboard start
3 · Conéctalo a Claude Code
$ claude mcp add cortex -- npx cortexboard mcp --actor ai-agent
4 · Dile a tu agente
Empieza tu tarea de Cortex: llena el árbol desde el código.

Ojo: lo que escriba tu agente queda como borrador. Apruébalo en localhost:4747.
