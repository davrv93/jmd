RTK: un filtro entre tus comandos y el modelo

RTK (Rust Token Killer) corre el comando de verdad y le entrega al modelo una versión corta, con los errores a la vista.

  1. 1 · el agente

    Pide git status

    Como siempre: no sabe que RTK existe.

  2. 2 · el hook

    Lo reescribe

    rtk rewrite lo cambia a rtk git status. Lo deja rtk init -g.

  3. 3 · RTK

    Corre y filtra

    Quita relleno, agrupa, deduplica. Los errores no se tocan.

  4. 4 · el modelo

    Lee lo que decide

    Menos tokens por vuelta. rtk gain lo cuenta.
