OpenCode es la ventana; el gateway, la puerta a los modelos

$ npm i -g opencode-ai    # instalar (Node 18+)$ opencode --version      # comprobar$ export GATEWAY_API_KEY="tu clave personal"$ opencode                # abrir el agente> hola                    # tu primera pregunta

Dónde van la URL y la clave opencode.json

"baseURL": "URL-DEL-GATEWAY/v1",   // la URL de clase
"apiKey":  "{env:GATEWAY_API_KEY}" // la clave, no aquí
Tu clave vive en una variable de entorno, nunca escrita en el archivo
Pulsa «Lo logré» en el panel cuando termines
