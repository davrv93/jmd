# Dudas verificables

> Una duda es una **afirmación** que no puedes sostener todavía, más la forma **concreta** de comprobarla. Sin «creo que»: o se comprueba, o queda abierta.

| # | Afirmación dudosa | De dónde sale | Cómo comprobarla (comando o prueba exacta) | Resultado | Estado |
|---|---|---|---|---|---|
| 1 | _(Ej.: «el bloqueo dura `bloqueoMin` minutos»)_ | `FOTO.md` §10 / `js/30-seguridad.js:_(línea)_` | _(Ej.: fallar la clave 6 veces, esperar 1 min, reintentar)_ | _(Qué pasó, con captura o salida pegada)_ | abierta / confirmada / refutada |
| 2 | | | | | |

## Reglas

- Cada fila termina en **confirmada**, **refutada** o **abierta** (si falta acceso o tiempo, dilo).
- El resultado cita `archivo:línea` o pega la salida del comando. Nunca solo «funciona».
- Si una afirmación de `FOTO.md` resulta falsa, anótala aquí y avisa al instructor: la foto es una pista, no un juez.
- Máximo 10 dudas: las que más cambiarían tu conclusión.
