    Etapa 1 · Puntos de entrada

    ¿Por dónde arranca el sistema? Busca manifiestos con scripts, un Dockerfile, una carpeta bin/ y el archivo que llama a listen. Marca los que creas y pulsa «Revelar entradas». Un archivo que define cosas pero nadie ejecuta directo no es una entrada.

    Etapa 2 · Componentes (qué hace cada carpeta)
    src/rutasHTTP: ventas, productos, pagos. express.Router()
    src/serviciosReglas: stock, IGV, SUNAT. Sin HTTP ni SQL.
    src/db.js + migraciones/Conexión pg y SQL versionado.
    Dependencias · solo flechas vistas en un import o en el manifiesto
    • server.js → app.js → rutas/*.js
    • rutas/ventas.js → servicios/stock.js, servicios/igv.js, db.js
    • rutas/pagos.js → db.js
    • bin/migrar.js → db.js, migraciones/*.sql
    • externas: express, pg package.json dependencies
    • servicios/sunat.js ningún archivo lo importa
