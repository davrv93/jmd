Insignia encendida. El umbral es 5 de 7 pasos. Con las tres sesiones completas, el LMS emite el certificado del curso.

Entrega final · desde el LMS (URL del repo + commit)

  1. Pide el borrador sin interacción y con citas: dsh --profile headless "Escribe docs/README-borrador.md solo con lo que verifiques en este repo; cita archivo y línea en cada afirmación y marca [SUPUESTO] lo que no puedas comprobar"
  2. Arma el paquete en docs/: README.md, ARQUITECTURA.md (mapa de componentes), FLUJOS.md (Mermaid), EJECUCION.md (instalación + diagnóstico) y REVISION.md (el procedimiento de 5 pasos)
  3. Valida: corre cada comando de EJECUCION.md en un clon limpio, comprueba las rutas con el bucle de la escena 4 y deja los [PENDIENTE: motivo] visibles
  4. Sube y entrega: git add README.md docs/ && git commit -m "docs: paquete validado" && git push

Afirmar con evidencia

Documento + código + prueba. Si falta una, se marca; no se escribe como hecho.

La guía se ejecuta

Rutas y comandos corridos hoy, fecha anotada. Lo que no se probó, pendiente visible.

Revisión al cambiar

Diff → módulos → documentos → borrador citado → ejecutar → marcar y fechar.
