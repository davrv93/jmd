# Instrucciones para el agente · GoldenQuerys

- El negocio del alumno está en `goldenquerys/MI_NEGOCIO.txt`. Trabaja solo con esa base, salvo que el alumno pida otra.
- Antes de construir nada, lee `goldenquerys/skill-dashboard/SKILL.md` y síguelo.
- El plan está en `goldenquerys/PLAN_TRABAJO.md`. Marca una tarea como `hecha` solo después de ejecutar su criterio.
- Las bases son de solo lectura: nunca abras un .sqlite para escribir ni lo copies para modificarlo.
- Si la API no responde, corre `sh goldenquerys/arrancar.sh`.
- Explica cada SQL en una línea en español para que el alumno aprenda. No escribas más de lo que te pidieron en esa tarea.
