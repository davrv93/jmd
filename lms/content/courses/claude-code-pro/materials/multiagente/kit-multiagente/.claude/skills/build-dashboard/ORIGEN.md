# De dónde sale esta skill

`SKILL.md` es la skill **build-dashboard** del plugin `data` de Anthropic, copiada sin cambios de
https://github.com/anthropics/knowledge-work-plugins/blob/main/data/skills/build-dashboard/SKILL.md
el 21-11-2026. Licencia Apache 2.0 (archivo `LICENSE` en esta carpeta).

Para instalar el plugin completo (con sus skills hermanas: sql-queries, explore-data,
data-visualization…) en lugar de esta copia:

    claude plugin marketplace add anthropics/knowledge-work-plugins
    claude plugin install data@knowledge-work-plugins

En clase usamos solo esta skill: cada skill instalada suma su descripción al contexto de arranque.
