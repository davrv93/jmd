El manual: cómo hacer tableros

Una skill es un manual que Claude abre solo cuando lo necesita. Buscamos el mejor manual gratuito para hacer tableros y ganó el de Anthropic, los creadores de Claude. Ya viene en tu kit.

Los manuales que comparamos
ManualDe quiénLargoQué tal
build-dashboardAnthropic, gratuito924 líneasElegido. Trae el modelo del tablero: cifras, gráficos, filtros y tabla
dashboard-creatorComunidad, gratuito78 líneasCorto y barato, pero se queda en lo básico

Lo que hace el manual

  1. Pregunta primero

    Para qué es el tablero, quién lo verá y qué números importan.

  2. Ordena la pantalla

    Arriba 2 a 4 cifras grandes, luego 1 a 3 gráficos y abajo una tabla.

  3. Un solo archivo

    Una página que abres con doble clic en el navegador, con gráficos y filtros.

Compruébalo tú 
ls .claude/skills/build-dashboard
/context

En la fila Skills verás que el manual casi no ocupa: Claude solo tiene a la vista su portada (unas 60 palabras). Lo abre entero cuando alguien pide un tablero, y en la escena 6 lo abre el ayudante constructor, no tú.

Opcional: el paquete completo de Anthropic para datos.

claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install data@knowledge-work-plugins
