Dos sesiones a la vez, sin pisarse

Como dos personas que trabajan en copias distintas del mismo documento: cada Claude tiene su propia carpeta (un worktree) y no pisa el trabajo del otro. Lo muestra el profe; si te sobra cuota, hazlo tú.

  1. Guarda una primera versión de la carpeta

    git init -q && git add -A && git commit -qm base

  2. Abre un segundo Claude en su propia copia

    claude -w tema-oscuro
    Agrega a dashboard.html un interruptor de tema claro/oscuro.

  3. Mientras tanto, el primer Claude sigue con otra cosa

    Con duckdb -readonly tokens.duckdb: ¿cuántos tokens de salida hizo cada tipo de subagente?
