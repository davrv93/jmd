Línea base: el render a lo bruto

Sin reglas, sin plantilla, sin pensar mucho el pedido. Como lo haría cualquiera el primer día. ¿Cuánto marca el taxímetro?

  1. Carpeta vacía y sesión nueva

    $ mkdir base && cd base && claude

    ¿Ya tenías una abierta? Escribe /clear. La mochila debe estar vacía.

  2. Pega este pedido, tal cual

    Haz un gráfico de barras 3D con p5.js en index.html, con 6 meses de ventas inventadas, que gire y se vea bien.

    Si te pregunta algo, responde «lo que tú decidas». Deja que trabaje.

  3. Abre el resultado y mira cuánto costó

    $ open index.html   # Windows: start index.html · Linux: xdg-open index.html
    > /context
    Ejemploclaude-opus · 38.4k/200k tokens (19%) → escribe 38400 o 38.4k
—tokens sin reglas

Al publicar, tu número cuenta como evidencia. En la escena 9 lo hacemos otra vez, con reglas, y comparamos.
