Reglas fijas, 40 líneas o menos

Se lee en cada sesión: cada línea cuesta siempre.

  1. Pídelo así

    Escribe CLAUDE.md en 40 líneas o menos:
1. Stack y el comando que corre las pruebas.
2. De 3 a 5 reglas que no se negocian (p. ej. «el chat solo hace SELECT»).
3. «El plan está en PLAN.md; el traspaso, en HANDOFF.md.»
4. «Para ubicar código, usa graphify query antes de abrir archivos.»
Nada de historia ni explicaciones largas.

  2. Cuéntalo

    $ wc -l CLAUDE.md

El mapa del código, sin gastar tokens

graphify update lee el código con un analizador, no con el modelo.

  1. Instálalo (una vez)

    $ uv tool install graphifyy

    ¿Sin uv? pipx install graphifyy. El paquete lleva dos «y».

  2. Arma el grafo de tu repo

    $ graphify update .

    Deja graphify-out/ con el grafo y un reporte.

  3. Pregúntale en vez de leer

    $ graphify query "ticket promedio"
$ graphify affected "fact_ventas"
