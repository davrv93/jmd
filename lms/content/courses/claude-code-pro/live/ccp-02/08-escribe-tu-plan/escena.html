Escribe tu PLAN.md

Primero el plan, después el código. En modo plan Claude solo lee: gasta poco y no toca nada.

  1. Entra en modo plan

    Shift+Tab dos veces, hasta ver plan mode on abajo.

  2. Pide el plan recursivo

    Vamos a construir el backend de un dashboard BI: ventas.csv → DuckDB con modelo estrella → API de 10 métricas con pruebas.
Escribe PLAN.md con un plan recursivo:
- Divide cada tarea hasta que sea una hoja: 1 cosa, cabe en 1 sesión, 1 prueba que la verifica.
- Máximo 3 niveles. Cada hoja con su criterio de parada: el comando exacto y lo que debe salir.
- Fases en orden, cada una con su casilla [ ].
- No escribas código todavía.

  3. ¿Una hoja con dos pruebas? Pídele que la divida

    La hoja «…» tiene dos pruebas: divídela en dos hojas y actualiza PLAN.md.
Revisa tu plan
  • Cada hoja tiene una prueba, con su comando
  • Ninguna hoja dice «y» (serían dos cosas)
  • Máximo 3 niveles
  • Fases en orden, con [ ]
  • Ni una línea de código todavía

Al publicar, tu plan cuenta como evidencia de esta escena.
