Hoy programas un editor de video con Claude

Con Claude Code harás una página para armar un video con imágenes, textos y música. Luego HyperFrames lo convierte en un MP4 y tú lo pruebas como un equipo de calidad.

Ten a la mano

  • editor-video.zip descargado desde Materiales

Comprueba tu computadora (en la terminal) 
npx hyperframes doctor

Revisa lo que HyperFrames necesita. Node.js (v22 o más), FFmpeg y FFprobe deben tener ✓; lo «optional» y Docker no hacen falta. Si falta FFmpeg: Mac brew install ffmpeg · Windows winget install Gyan.FFmpeg

Regla del curso: ponemos nota al empezar y al terminar, para ver si de verdad mejoró.
