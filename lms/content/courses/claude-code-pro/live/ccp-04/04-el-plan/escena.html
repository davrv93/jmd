Conducir 1: primero el plan

Ahora sí, con el kit. Le cuentas a Claude qué quieres y le pides un plan corto antes de que escriba una sola línea. Corregir un plan es gratis; rehacer un programa, no.

  1. Di qué quieres

    Quiero programar un editor de video muy simple, para gente que no sabe editar. En esta carpeta tienes imagenes/, musica/ y proyecto-ejemplo.json, que muestra cómo guardo la línea de tiempo: clips de imagen, texto y música, con inicio y duración en segundos. La carpeta video/ es un proyecto de HyperFrames.

  2. Pide el plan, sin código

    Antes de escribir código, propón un plan corto con: 1) las pantallas del editor, 2) cómo guardas la línea de tiempo (usa el formato de proyecto-ejemplo.json), 3) cómo un script de Node convierte proyecto.json en video/index.html, una composición de HyperFrames, 4) qué revisa antes de exportar y 5) cómo lo vamos a probar. Usa la skill hyperframes. No escribas código todavía.

  3. Aprueba, con tus cambios

    Aprobado, con este cambio: [tu cambio]. Construye solo la pieza 1 y espera a que la revise.
Antes · prepara la carpeta

Sal con /exit, descomprime editor-video.zip y pega en la terminal:

cd editor-video
npx hyperframes init video --non-interactive
claude

Crea la carpeta video, instala en Claude Code los manuales de HyperFrames y abre Claude.

Un buen plan tiene…
  • editor.html, que se abre con doble clic
  • Las reglas aparte, en lib.js, para probarlas
  • exportar.js: escribe video/index.html y copia los archivos
  • Revisa duración, textos largos y fotos encimadas
  • Cada cuadro depende solo del tiempo

Si Claude empieza a escribir código antes de tiempo, pulsa Esc y repítele: «solo el plan».
