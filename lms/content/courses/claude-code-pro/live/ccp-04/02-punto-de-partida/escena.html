Punto de partida: una sola frase

Primero pedimos el editor como lo haría cualquiera, sin explicar nada, y le ponemos nota. Así veremos cuánto mejora cuando lo conducimos.

  1. Abre Claude Code en una carpeta vacía

    mkdir editor-vago; cd editor-vago; claude

    Funciona igual en Mac y en Windows (PowerShell). Es una carpeta de prueba: no la usaremos después.

  2. Pide solo esto

    Hazme un editor de video.

    A propósito, sin más detalles. Si Claude te pregunta algo, responde «decide tú». Dale 10 minutos como máximo.

  3. Mide cuánto se llenó la mesa

    /context

    Es la mesa de trabajo de Claude (sesión 3). Anota el porcentaje: lo usarás en tu reporte de tokens.

  4. Ábrelo y ponle nota

    Pregúntate: ¿puedo armar un video de 15 segundos con 3 imágenes, textos y música, y sacar un MP4? Si no se puede, la nota es baja aunque se vea bonito.
